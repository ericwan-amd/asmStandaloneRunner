doSwizzle memory layout

Original 0–511 continuous buffer vs after permute {0,2,3,1,4}. Same 512 elements, different linear order.

Original (before doSwizzle) 16×32 row-major

Linear index = row×32 + col. Row 0: 0..31, row 1: 32..63, …

After doSwizzle (permute) content = original index at this new position

Each cell shows which original index now lives here. new_linear = 128×s3 + 8×s1 + s4.
